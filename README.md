## Gambaran Singkat Proyek Tugas Akhir
## Judul: Digitalisasi Pemesanan dan Validasi Tiket Bus Trans Citra Raya melalui Aplikasi Mobile Berbasis QR Code.

Proyek Tugas Akhir ini berfokus pada perancangan prototipe aplikasi mobile untuk mendukung proses pemesanan dan validasi tiket bus Trans Citra Raya. Ruang lingkup yang dibahas meliputi informasi rute dan jadwal, pemesanan tiket, pemilihan kursi, penerbitan tiket elektronik, serta pemindaian dan validasi QR Code oleh petugas. Implementasi dan fitur yang belum selesai tidak dinyatakan sebagai fitur yang telah berjalan.
